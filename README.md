# CSCI-C212_final_project
For the final project of CSCI-C212, I chose to complete a primitive image editor, and weather report able to be returned in the terminal, through API connectivity. I worked with 3 other people in this project, but on top of my own workload, I helped everyone else with their respective portions of the project (as I was able to quickly learn the new concepts presented in this project). Refer to the group work documentation for more details. 

To use the image editor, run the ImageEditorRunner class.
To use the weather forecast, run the WeatherForecast class. To change the weather forecast, utilize terminal arguments for your IDE. (For more help, refer to this guide: https://users.drew.edu/bburd/JavaForDummies6/CommandLineIntelliJIDEA.pdf) 

The format is as follows:
./WeatherForecast --latitude X --longitude Y --unit Z
Where X is the location's latitude, Y is the location's longitude, and Z is either C or F (for Celsius, or Fahrenheit, respectively). 

In the end, we received an 100 on the project.
